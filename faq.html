Architecture & Design Q&A

Questions & Technical Answers

Everything you need to know about the construction, accessibility, and pure CSS features of this assignment.

Why is this entire portfolio website built using only HTML5 and CSS3 without JavaScript?

This project was created for Web Engineering Assignment 1. The objective of this assignment is to master the foundational mechanics of the modern web platform: semantic markup structuring, document outline hierarchy, CSS Grid, CSS Flexbox, and responsive design systems.

By strictly omitting JavaScript and frameworks like React or Bootstrap, the codebase demonstrates that high-performance, aesthetically pleasing, and interactive user interfaces can be created purely with the native browser rendering engine.

How is responsive design achieved across mobile, tablet, and desktop viewports?

Responsive design is achieved through a combination of fluid layout grids and targeted CSS3 media queries:

  • CSS Grid Auto-Fit: Multi-column cards use grid-template-columns: repeat(auto-fit, minmax(...)) which naturally wrap without requiring breakpoints.
  • Breakpoints at 1024px & 768px: As screen real estate narrows, 4-column grids collapse to 2 columns, and ultimately to a single comfortable vertical column on mobile screens.
  • Relative Units: Spacing and typography rely on relative units (rem, em, %) ensuring text scales gracefully when users adjust their device font size settings.
How does the mobile navigation hamburger toggle work without any JavaScript?

The mobile navigation uses a celebrated pure CSS technique known as the Checkbox Hack:

  1. A standard HTML checkbox <input type="checkbox" id="nav-toggle" class="nav-toggle"> is placed at the top of the header and hidden with display: none.
  2. A semantic <label for="nav-toggle"> containing three CSS span bars is displayed as the hamburger icon on mobile viewports.
  3. When the user taps the label, the browser natively toggles the checkbox's state. In CSS, the selector .nav-toggle:checked ~ .site-nav targets the adjacent navigation drawer and sets display: flex, while animating the hamburger bars into an "X"!
How does the interactive image lightbox on the Gallery page function without JavaScript?

The gallery modal operates using the CSS3 :target pseudo-class:

Each gallery thumbnail links to an element ID (for example, href="#preview-1"). When clicked, the browser appends #preview-1 to the URL. The CSS rule .lightbox-modal:target { display: flex; } immediately activates the full-screen overlay. Clicking the modal close button (which links back to #gallery) changes the URL hash, effortlessly dismissing the modal with zero scripts.

How is the CSS organized across all 10 pages without duplicating code?

All styles reside in a single external stylesheet: css/style.css. Every HTML document includes the same <link rel="stylesheet" href="css/style.css"> tag in its <head>.

The stylesheet is architected using CSS Custom Properties (Variables) in the :root scope for brand colors, elevation shadows, typography, and border radii. Reusable utility classes (.container, .grid-2, .grid-3, .btn, .card) allow consistent layout generation across all 10 pages.

What accessibility and inclusive design considerations were incorporated?

Accessibility was considered throughout the design and markup phases:

  • WCAG 2.1 AA Contrast: The navy text on light backgrounds and white text on primary purple buttons exceed the minimum contrast ratio of 4.5:1.
  • Keyboard Navigation: All interactive links and buttons feature visible focus indicators (:focus-visible) for keyboard-only users.
  • Accessible Forms: Every input element in the contact form features an explicitly associated <label for="..."> tag.
  • Screen Reader Landmarks: All pages utilize semantic landmark tags (<header>, <nav>, <main>, <article>, <footer>) and descriptive alt attributes on all images.
Why are local SVG images used instead of third-party external image URLs?

External image URLs frequently suffer from network latency, rate limits, or broken link 404 errors. By storing handcrafted vector SVG graphics locally in the images/ folder:

  • The website functions completely offline without an active internet connection.
  • Vector graphics scale crisply to any screen resolution (from mobile phones to 4K displays) without pixelation.
  • The total download payload remains minuscule, enabling instantaneous page load speeds.
